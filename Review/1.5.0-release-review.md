## Verified as OK

**Crashes / data loss / backups / migrations**

- `BackupService` and `Expense` SwiftData schema are unchanged since 1.4.0. Isolated replacement and validation remain.
- Voice Save inserts through an isolated context (S3). Ledger writes from voice are insert-only. Editor delete cannot fire with one tap.
- Screenshot launch arguments can wipe the ledger only when `--screenshot-*` is passed.

**Voice Mode — OpenAI**

- `gpt-realtime-2.1` via the user’s Keychain key. No Mäuse backend. Workspace context is still sent on connect.

**Voice Mode — Apple**

- No credentials, no network client, no OpenAI fallback. SpeechAnalyzer + on-device `SpeechTranscriber` (else `DictationTranscriber`), then `SystemLanguageModel.default`.
- One expense at a time. Unavailable Apple mode opens setup instead of a failing session.

**iPhone Duo / adaptive layout**

- Width-based, not a Duo-only API. Month review at ≥700 pt (and not accessibility text size) is two columns: 320 pt totals/split + ledger (`MainExpenseView.swift:22-90`). Height < 500 pt moves capture buttons into the header.
- Welcome ≥760 pt: intro beside steps. Settings ≥720 pt: general settings beside Voice Mode. OpenAI Voice Mode ≥760 pt: capture rail beside drafts. Apple Voice Mode stays a single column. Chooser ≥720 pt: two provider cards; short sheets hide the emblem so both modes stay on screen.
- Accessibility text sizes force one column. Closed/narrow Duo is the regular iPhone layout. Tests cover inner portrait/landscape, Closed, and Partially Open.

**Consent, privacy, keys**

- OpenAI disclosure once. Off keeps consent; deleting the key withdraws it. `currentConsentVersion` is **2**. Apple mode has no disclosure.
- API key: Keychain only. Privacy manifest: UserDefaults `CA92.1` and System Boot Time `35F9.1`. Microphone purpose string names OpenAI vs Apple.
- Nutrition Labels unchanged because OpenAI mode still exists.

**Localization / accessibility / Review risk**

- EN/DE `Localizable.strings`: 236 keys each. Residual English “Voice Mode” in German widgets is N12.
- Core app remains usable without Voice Mode, without a key, and offline.
