## Recommendation

**No release blockers in source.** Backup import/export, the expense schema, and the OpenAI transport are unchanged in kind from 1.4.0. Apple mode keeps audio on-device (SpeechAnalyzer + SpeechTranscriber / DictationTranscriber, then `SystemLanguageModel.default`; no OpenAI fallback). Consent, Keychain, and 1.4 upgrade migration have regression tests.

Ship **build 64** unless you want the microphone purpose-string clarification below. That change is the only should-fix that alters the binary. It lives on `cursor/mic-purpose-string-5f1a` and **requires a new build** if you take it. Everything else in this review is documentation, screenshots, or App Store Connect work.

Physical Apple speech, the speech-model download, and interruption recovery are still **device checks**. Simulator tests and Mac model scripts do not replace them.

## Verified as OK

**Crashes / data loss / backups / migrations**

- `BackupService` and `Expense` SwiftData schema are **unchanged** since 1.4.0. Isolated replacement, validation of amounts/splits/IDs/strict dates, and failed-save preservation of the live ledger remain. Persistence tests still cover restore and invalid input.
- Expense editor delete is a centred `.alert` (not a top-left popover) with Cancel + destructive Delete. `Maeuse/Views/ExpenseEditorSheet.swift:54-61`.
- Screenshot launch arguments can wipe the ledger (`ContentView.swift:185-204`) only when `--screenshot-*` is passed. Not reachable in the store binary.

**Voice Mode — OpenAI**

- Still `gpt-realtime-2.1` via the user’s Keychain key. No Mäuse backend. Workspace context (current drafts) is still sent on connect (`VoiceModeViewModel.swift:416-431`).
- Session configuration now shares Apple’s split-intent / unclear-date rules. OpenAI behavior is otherwise the 1.4.0 flow: continuous capture, compact cards, “What I understood,” explicit Save.

**Voice Mode — Apple**

- `AppleLocalVoiceService` has no credentials, no network client, and no reference to the OpenAI service (`AppleLocalVoiceService.swift:224-226`).
- Capture is SpeechAnalyzer + on-device `SpeechTranscriber` (else `DictationTranscriber`). Assets download once, then work offline. `SystemLanguageModel.default` is the on-device model; Private Cloud Compute is not wired (see `Docs/apple-voice-feasibility.md`).
- iOS 17: availability returns `.needsOS` before SpeechAnalyzer or Foundation Models APIs run. Speech/FoundationModels types are `@available(iOS 26.0, *)` or stored untyped.
- Unavailable Apple mode opens setup instead of a session that fails immediately (`SettingsViewModel.swift:162-167`; `MainExpenseView.swift:220-230`). Availability refreshes on foreground.
- One expense at a time: several priced purchases prompt `LocalOneAtATime`; a complete draft pauses the mic; Save commits that row and listens for the next; Done closes; ✕ discards. Closing without Save drops in-memory drafts only (same contract as OpenAI).

**Consent, privacy, keys**

- OpenAI disclosure once per key lifetime. Turning Voice Mode off stops capture and keeps consent. Deleting the key (or losing it from Keychain) withdraws consent and turns OpenAI off. Apple mode has no disclosure (`VoiceSettings.requiresConsent`, `SettingsViewModel.swift:97-99,208-213`).
- 1.4 installs without cloud evidence migrate to Apple and still see the chooser; cloud setup keeps OpenAI and skips the chooser; a fresh install stores nothing until a choice (`LocalVoiceTests` 1.5.0 review regressions).
- API key: Keychain only; suffix in UserDefaults; never in backups or diagnosis export. Diagnosis export is asserted not to contain transcripts in tests.
- Privacy manifest unchanged: `NSPrivacyAccessedAPICategoryUserDefaults` / `CA92.1` in app and Controls. `ITSAppUsesNonExemptEncryption` remains `false`.
- Speech recognition purpose string correctly states on-device Apple mode.

**Localization / accessibility / Review risk**

- EN/DE `Localizable.strings`: 236 keys each, no missing keys, no placeholder mismatches.
- VoiceOver: Apple state changes announced; microphone value not double-read; Change-mode control labeled; Reduce Motion honored on capture motion.
- Core app remains usable without Voice Mode, without a key, and offline. Apple Intelligence is optional. No IAP; OpenAI charges the user’s API project (same 3.1.1 position as 1.4.0).
- Debug/preview UI is `#if targetEnvironment(simulator)` or `#if MODEL_EVALUATION`.

**OpenAI retention (rechecked 2026-10-23)**

[OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data): `/v1/realtime` is not used for training by default; abuse-monitoring retention 30 days; no application-state retention; ZDR-eligible. Privacy Nutrition Labels stay as in 1.4.0 because OpenAI mode still exists. Apple mode adds no new collected-data category.
