# 1.3.1 review fixes

September 21, 2026. Fixes after `11e0c3c` (TestFlight build 44), included in the 1.3.1 build 45 TestFlight candidate. Foundation Models research remains documentation only. This report records verification before distribution; see the release checklist for distribution status.

## Resolutions

| Review finding | Change | Regression coverage |
| --- | --- | --- |
| Unsafe backup values can crash the ledger | Validate positive finite money up to €999,999,999.99, percentage splits in 0–100, fixed splits, IDs, and strict ISO dates before replacement. Guard rendering/editing of invalid existing splits. | Import and direct replacement reject invalid entries without changing existing rows; legacy invalid splits render/edit without integer traps. |
| Failed restore corrupts the live context | Stage replacement in a separate context with autosave disabled; save once and discard it on failure. | Actual read-only-store write failure; original rows checked in live and fresh contexts. Successful same-ID replacement and mounted SwiftData query refresh are tested separately. |
| Late voice result restores a removed card | Keep manually removed IDs retired for the session, including across reconnection. Instruct the model to use a new ID for an explicit re-add. Local notes no longer start competing responses. | Stale full snapshot cannot restore the card; a new ID is accepted. |
| Failed/malformed responses disappear silently | Apply tool results only from successfully completed responses; validate all tool calls before publishing any. Show localized errors for failed, incomplete, or malformed results. | Failed/incomplete/malformed/cancelled responses, atomic multi-tool handling, and response deduplication. |
| Old callbacks mutate a closed session | Main-actor ownership of transport/parser state, synchronous delegate delivery, and connection-generation guards on socket, audio, and notification callbacks. Closing invalidates the generation and cancels connection setup. | Queued old response delivered after cancellation and again after reopening cannot mutate the workspace. |
| Invalid voice dates become today | Explicit invalid dates block saving and ask for correction. Only an omitted date receives today's default. | Malformed/nonexistent dates rejected; leap day and omitted date handled correctly. |
| Interruptions leave a false listening indicator | Observe interruptions, route/configuration changes, and media-service loss/reset. Stop capture and offer Resume listening while preserving drafts/history. Reconnection sends the current workspace before capture starts. | Lifecycle state transitions, notification mapping, preserved resume context, and cancellation before reconnect starts. |
