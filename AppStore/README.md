## Files

- `metadata-en.md`: English product-page copy.
- `metadata-de.md`: German product-page copy.
- `privacy-answers.md`: recommended App Privacy answers and their rationale.
- `compliance-answers.md`: age rating, content rights, export, tracking, business-model, accessibility, and DSA answers.
- `review-notes.md`: copy-ready App Review notes with placeholders for a temporary reviewer key.
- `testflight.md`: bilingual beta descriptions, focused test instructions, and Beta App Review guidance.
- `ExportOptions.example.plist`: reproducible App Store Connect distribution-export settings for Xcode.
- `submission-checklist.md`: ordered App Store Connect and release checklist.
- `screenshots/README.md`: screenshot order, captions, and technical specifications.

Do not place a real OpenAI API key in this repository. Add a temporary reviewer credential only in App Store Connect immediately before submission and revoke it after review.
